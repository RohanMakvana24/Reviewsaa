# Phase 01 — Product scope and brand

Status: Not started

## Dependencies

None.

## Implementation checklist

- [ ] Confirm the brand spelling: latest user spelling is ReviesNest; ReviewsNest was the earlier suggestion. Keep branding configurable until confirmed.
- [ ] Freeze MVP roles: Platform Super Admin and Business Owner. Customers scanning a QR page do not need an account.
- [ ] Use Next.js + TypeScript for frontend, Express + TypeScript for backend, MySQL + Prisma for database, and Redis + BullMQ for background work.
- [ ] Set the initial proposed offer to ₹99/month, one Google Business Profile, 30 AI generations/month, and a 14-day trial with 20 generations total. Prices and allowances remain configurable; annual pricing requires a final decision.
- [ ] Exclude AutoPay, recurring mandates, staff roles, advanced builder, and multi-branch paid tiers from MVP. Allow the data model to support multiple locations later.
- [ ] Define success as a real consenting pilot business completing onboarding, receiving value, and making a manual payment.

## Acceptance criteria

A written MVP scope, configurable initial offer, and explicit exclusions are agreed.

## Handoff

Record changed files, validation performed, unresolved dependencies and any scope decisions. Review this phase before starting the next dependent phase. Never mark mock integrations as complete live integrations.
